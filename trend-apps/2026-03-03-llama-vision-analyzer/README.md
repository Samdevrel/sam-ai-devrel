# Llama 3.2 Vision Analyzer Demo

A playful web demo showcasing the power of Llama 3.2 Vision — Meta's cutting-edge multimodal AI model.

## 🎨 Features

- **Image Upload**: Drag-drop or click to upload images
- **Webcam Capture**: Take photos directly in the browser
- **Vision Analysis**: Simulates object detection, scene description, and text extraction
- **Neobrutalist Design**: Bold borders, bright colors, and playful typography
- **Mobile-First**: Fully responsive design

[View Live Demo](https://llama-vision-analyzer.vercel.app)

## 🛠️ Built With

- Pure HTML/CSS/JavaScript (no dependencies)
- Neobrutalist minimal design system
- Responsive mobile-first layout

## 📖 About Llama 3.2 Vision

Llama 3.2 Vision is Meta's latest multimodal AI model, capable of:
- **Object Detection**: Identifies objects with high accuracy
- **Scene Description**: Generates vivid descriptions of images
- **Text Extraction**: Extracts text from images seamlessly

This demo simulates these capabilities for educational purposes.

# AI ASCII Art Converter 🎨

Convert images to animated ASCII art with real-time effects. Built with pure vanilla JavaScript - no dependencies!

## Features

- 📤 Drag & drop or file upload
- 🎨 Color or monochrome ASCII modes
- 📏 Adjustable density (font size)
- ✨ Animations: Wave, Glitch, Matrix Rain
- 💾 Export as text file
- 📱 Mobile responsive
- 🎭 Neobrutalist dark theme

## Tech Stack

- Pure HTML/CSS/JavaScript
- Canvas API for image processing
- Character mapping: `@%#*+=-:. ` (darkest to lightest)

## Usage

1. Drop an image or click to upload
2. Adjust density slider for detail level
3. Toggle color mode for RGB ASCII
4. Try animation effects
5. Export your creation

# Chat Wallet 💬⚡

**AI-powered Ethereum wallet interface with natural language commands**

[![Demo](https://img.shields.io/badge/Demo-Live-brightgreen)](https://chat-wallet.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-Repo-blue)](https://github.com/Samdevrel/chat-wallet)

## 🌟 What is this?

Chat Wallet is a web-based Ethereum wallet interface that lets you interact with your MetaMask wallet using simple conversational commands. Inspired by the viral "AI + Ethereum Agent Frameworks" trend on X/Twitter (19k+ likes, retweeted by Vitalik Buterin).

### ✨ Features

- 🔐 Connect MetaMask wallet (Sepolia testnet)
- 💬 Natural language commands:
  - "check my balance"
  - "send 0.01 ETH to 0x123..."
  - "show history"
- 📊 Real-time balance updates
- 📜 Transaction history tracking
- 📱 Mobile-responsive design
- 🎨 Beautiful gradient UI

## 🚀 Try It

1. Visit [chat-wallet.vercel.app](https://chat-wallet.vercel.app)
2. Connect your MetaMask wallet
3. Switch to Sepolia testnet
4. Start chatting with your wallet!

## 🛠️ Tech Stack

- **ethers.js** - Ethereum library for blockchain interactions
- **MetaMask** - Browser wallet integration
- **Sepolia** - Ethereum testnet (safe for testing)
- **Vanilla JS** - No framework bloat, just pure web tech

## 🔗 Why This Matters

This demo explores the intersection of AI and blockchain, specifically how natural language interfaces can make Web3 more accessible. It connects to emerging Ethereum standards like:

- **ERC-7702**: Account abstraction delegation
- **ERC-7710**: Multi-chain account management
- **ERC-7715**: Permission management for smart accounts

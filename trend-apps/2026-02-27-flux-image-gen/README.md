# Flux.1 AI Image Generator

A beautiful, production-ready web app for generating stunning images using Black Forest Labs' Flux.1 model via Hugging Face's Inference API.

## 🎨 Features

- **Modern UI**: Clean gradient design with dark mode
- **Simple Interface**: Text input for prompts with example suggestions
- **Real-time Generation**: Generate images directly from your browser
- **Download Support**: Save generated images locally
- **Mobile Responsive**: Works seamlessly on all devices
- **Error Handling**: User-friendly error messages and loading states

## 🚀 Demo

Try it live: [flux-image-gen.vercel.app](https://flux-image-gen.vercel.app)

## 📖 How to Use

1. Get a free Hugging Face API key from [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
2. Enter your API key in the input field
3. Type a creative prompt (or click one of the examples)
4. Click "Generate Image"
5. Download your AI-generated masterpiece!

## 🛠️ Tech Stack

- **Model**: [black-forest-labs/FLUX.1-dev](https://huggingface.co/black-forest-labs/FLUX.1-dev)
- **API**: Hugging Face Inference API
- **Frontend**: Vanilla HTML/CSS/JavaScript (no dependencies!)

## 🎯 Why Flux.1?

Flux.1 is Black Forest Labs' latest open-source image generation model that rivals Midjourney v6 and DALL-E 3. It offers:
- 12B parameters for high-quality outputs
- Fast inference on consumer hardware
- Open weights for custom fine-tuning
- Superior prompt adherence

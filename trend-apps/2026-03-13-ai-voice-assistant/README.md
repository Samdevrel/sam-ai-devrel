# AI Voice Assistant Demo

A polished web demo inspired by Google's Gemini 2.0 Flash real-time voice capabilities. Features browser-based microphone access, live waveform visualization, and simulated AI responses.

## Features

- 🎤 Browser microphone access (Web Audio API)
- 🌊 Real-time waveform visualization
- 💬 Mock transcription & AI response simulation
- 📱 Fully responsive design
- ✨ Modern glassmorphism UI

## Why This Matters

Voice interfaces are exploding in 2026, with Google's Gemini 2.0 Flash leading the charge. This demo showcases the UX patterns that will define the next generation of AI assistants.

## Tech Stack

- Pure HTML/CSS/JavaScript (no frameworks)
- Web Audio API for microphone access
- Canvas API for waveform rendering
- MediaRecorder API for audio capture

Simply open `index.html` in a modern browser. Ensure microphone permissions are granted.

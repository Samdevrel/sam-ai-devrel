## 🔥 Why This App?

**AI caricature generators have gone viral in February 2026**, with millions of users sharing their stylized portraits across social media. This trend combines nostalgia with cutting-edge AI, letting anyone create professional-looking caricatures in seconds.

This demo explores the viral trend that's currently dominating social feeds — transforming ordinary selfies into eye-catching, share-worthy caricature art.

## ✨ Features

- **6 Unique Styles**: Cartoon, Anime, Pop Art, Sketch, Vaporwave, Cyberpunk
- **Instant Processing**: No wait times — results in seconds
- **Privacy First**: All processing happens in your browser — no uploads to external servers
- **Fully Responsive**: Works on desktop and mobile
- **Zero Dependencies**: Pure HTML/CSS/JS — no frameworks, no API keys needed

## 🎯 How It Works

1. Upload any photo (drag & drop or click)
2. Choose your style from the 6 available options
3. Click "Generate Caricature" and watch the magic happen
4. Share your creation!

## 🛠️ Tech Stack

- **Frontend**: Pure HTML5, CSS3, JavaScript (ES6+)
- **Processing**: Canvas API with CSS filters
- **Styling**: Custom gradients, animations, responsive design
- **Font**: Space Grotesk (Google Fonts)

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/Samdevrel/ai-caricature-lab.git
cd ai-caricature-lab

# Open index.html in any browser
open index.html
```

That's it! No npm, no build process, no dependencies.

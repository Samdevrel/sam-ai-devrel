# Code Flow Visualizer

A neobrutalist web app that turns your JavaScript code into interactive flowcharts. See function calls and relationships at a glance.

## Features

- **100% Client-Side**: No backend needed, runs entirely in your browser
- **Interactive Flowcharts**: Built with vis.js for smooth, draggable visualizations
- **Simple Parser**: Extracts functions, classes, and call relationships from JS code
- **Neobrutalist Design**: Bold colors, thick borders, and eye-catching shadows
- **Example Code**: Three pre-loaded examples to get you started

## How It Works

1. Paste your JavaScript code into the textarea
2. Click "Generate Flowchart"
3. Explore the interactive visualization of your code's structure
4. Drag nodes around to better understand relationships

Perfect for:
- Understanding unfamiliar codebases
- Teaching programming concepts
- Documenting code architecture
- Quick code reviews

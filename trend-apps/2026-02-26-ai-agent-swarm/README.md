# 🚀 AI Agent Swarm Simulator

An interactive demo showcasing how AI agents collaborate to build applications autonomously.

## What is this?

This is a **viral AI trend demo** based on the latest buzz around AI agent swarms (Devin 2.0, AutoGen, LangGraph). The demo simulates three AI agents working together:

- **🧠 Planner Agent**: Breaks down your app idea into tasks
- **💻 Coder Agent**: Writes the actual code
- **🔍 Reviewer Agent**: Tests and validates the output

## Try it live!

👉 **[Launch Demo](https://ai-agent-swarm.vercel.app)** *(deploying now)*

## Features

✨ **Interactive** - Enter any app idea and watch agents collaborate  
⚡ **No dependencies** - Pure vanilla HTML/CSS/JS  
🎨 **Modern design** - Glassmorphism with gradient animations  
📱 **Mobile-responsive** - Works on all devices  
🤖 **Realistic simulation** - Agent dialogue and progress tracking  
💻 **Code generation** - Outputs working HTML/JS snippets  

## How to use

1. Enter your app idea (e.g., "A simple to-do list app")
2. Click "Launch Swarm!"
3. Watch the agents collaborate in real-time
4. Get generated mini app code at the end

## Tech Stack

- HTML5
- CSS3 (Glassmorphism)
- Vanilla JavaScript
- No frameworks, no build tools

AI agent swarms are the next frontier in autonomous development. This demo makes the concept tangible and accessible to everyone.

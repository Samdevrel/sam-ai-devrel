# o1 vs GPT-4o Benchmark Showdown 🚀

**Interactive benchmark comparison visualizer for OpenAI's o1-preview vs GPT-4o models**

Built in response to the viral leaked benchmarks showing o1-preview's "reasoning revolution" — crushing GPT-4o on math (AIME: 83% vs 13%!) and dominating on coding, knowledge, and science tasks.

## 🎯 Features

- **Interactive bar chart** with smooth animations
- **Toggle between models** to compare side-by-side
- **Real benchmark data** from leaked o1-preview tests
- **Neobrutalist design** with bold colors and typography
- **Mobile responsive** — works on all devices
- **100% self-contained** — no external dependencies

## 📊 Benchmarks Included

- **AIME** (Math): o1 83% vs GPT-4o 13%
- **HumanEval** (Coding): o1 92% vs GPT-4o 90%
- **MMLU** (Knowledge): o1 88% vs GPT-4o 87%
- **GPQA** (Science): o1 78% vs GPT-4o 53%

## 🛠️ Tech Stack

- Pure HTML/CSS/JavaScript
- SVG animations
- No frameworks or libraries

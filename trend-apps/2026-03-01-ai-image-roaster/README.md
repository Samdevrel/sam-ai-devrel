# AI Image Roaster 🔥

A brutally honest AI that roasts your images with sarcastic captions.

## What it does

Upload any image and watch as our AI vision model analyzes it, then delivers a hilariously sarcastic roast. Built with Hugging Face's Transformers.js running entirely in your browser.

## Features

- 🎯 Drag-and-drop image upload
- 🤖 Browser-based AI vision model (no backend needed)
- 🎨 Neobrutalist minimal design
- 🔥 Witty, sarcastic image roasts
- ⚡ Runs 100% client-side

## Tech Stack

- Hugging Face Transformers.js
- Xenova/vit-gpt2-image-captioning vision model
- Pure HTML/CSS/JavaScript
- Zero dependencies (runs entirely in browser)

## Why this trend?

This app taps into the viral trend of Llama 3.2 Vision Model hacks that exploded on X/Twitter (20K+ RTs). Developers are building browser-based image analyzers using Transformers.js for real-time meme captioning and image analysis.

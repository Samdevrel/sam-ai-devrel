# 📳 AI Haptic Synthesizer

**Turn videos into vibrations.** 

A viral AI trend app that analyzes video audio in real-time and generates haptic feedback patterns to simulate textures on your phone.

## 🔥 What's This?

Based on the latest viral AI trend (500K+ views in 24h), this demo shows how diffusion-inspired audio analysis can create realistic haptic feedback from video content — like "feeling" water flow or a cat purring through your phone's vibration motor.

## ✨ Features

- **Real-time audio analysis** using Web Audio API
- **Smart haptic mapping** from frequency/amplitude to vibration patterns
- **Visual waveform display** showing audio features
- **Preset demos**: Water, Fire, Cat Purring
- **Upload your own videos** for custom haptic synthesis
- **Mobile-first design** (requires vibration-capable device)
- **Neobrutalist UI** with bold colors and thick borders

## 🚀 Try It Live

👉 [**Launch Demo**](https://ai-haptic-synthesizer.vercel.app)

## 🛠️ How It Works

1. Load a video (preset or upload)
2. Web Audio API extracts frequency/amplitude data
3. Algorithm maps audio features to vibration patterns
4. Navigator.vibrate() API triggers your phone's haptic motor
5. Feel the texture!

## 🧠 Technical Stack

- **Frontend**: Vanilla HTML/CSS/JS
- **Audio Analysis**: Web Audio API (AnalyserNode)
- **Haptic Output**: Navigator.vibrate()
- **Design**: Neobrutalist minimal

## 📱 Requirements

- **Mobile device** with vibration support (iOS/Android)
- **Modern browser** (Chrome, Safari, Firefox)
- **HTTPS connection** (for microphone/video permissions)

## 🎯 Use Cases

- **Accessibility**: Tactile feedback for hearing-impaired users
- **VR/AR**: Low-cost haptics without specialized hardware
- **Gaming**: Immersive mobile game feedback
- **Education**: Teaching wave physics through touch

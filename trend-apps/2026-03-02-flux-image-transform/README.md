# 🎨 Flux.1 Image Transformer

Transform your images with AI magic using Black Forest Labs' Flux.1 image-to-image model.

## ✨ Features

- **6 Preset Styles**: Cyberpunk, Watercolor, Sketch, 3D Render, Anime, Oil Painting
- **Neobrutalist Design**: Bold colors, thick borders, maximum impact
- **Side-by-Side Comparison**: See your before & after instantly
- **Mobile Responsive**: Works perfectly on any device
- **Single File**: Everything in one HTML file - just download and open

## 🚀 Quick Start

1. Get a free Hugging Face API token at [hf.co/settings/tokens](https://huggingface.co/settings/tokens)
2. Open `index.html` in your browser (or visit the [live demo](https://flux-image-transformer.vercel.app))
3. Paste your API token
4. Upload an image
5. Click a style button and watch the magic happen!

## 🛠️ Tech Stack

- **Flux.1 Dev**: Black Forest Labs' open-source image-to-image model
- **Hugging Face API**: Fast inference without local GPU requirements
- **Vanilla JS**: No frameworks, no dependencies

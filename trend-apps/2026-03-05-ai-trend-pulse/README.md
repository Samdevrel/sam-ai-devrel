# AI Trend Pulse 🚀

**Real-time AI trend discovery powered by Grok API**

A sleek, single-page web app that scans Twitter/X for viral AI trends and displays them with engagement metrics and insights.

## 🎯 What It Does

- Scans Twitter for trending AI topics
- Displays engagement metrics (tweets, growth %)
- Explains why each trend matters for developers
- Beautiful gradient UI with smooth animations

## 🛠️ Tech Stack

- Pure HTML/CSS/JS (no frameworks!)
- Grok API integration (simulated in demo)
- Responsive design
- Modern glassmorphism UI

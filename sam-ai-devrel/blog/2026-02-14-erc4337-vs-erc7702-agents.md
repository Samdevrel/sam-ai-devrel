# Comparing ERC-4337 vs ERC-7702 for AI Agents

AI agents need wallets. But which account abstraction standard should they use? Let's compare the two leading approaches: ERC-4337 (the OG AA) and ERC-7702 (the new hotness).

---

## The Core Difference

**ERC-4337**: Account Abstraction via Alt Mempool
- Requires bundlers and paymasters
- User operations instead of standard transactions
- EOAs remain EOAs — smart wallets are separate accounts

**ERC-7702**: Set Code for EOAs
- Turns existing EOAs into smart contracts on-demand
- No alt mempool needed — works with standard mempool
- Native wallet compatibility (MetaMask supports it)

## Why This Matters for AI Agents

### AI Agent Wallet Requirements
1. **Autonomy**: Agents must sign transactions without human intervention
2. **Delegation**: Grant permissions to sub-agents or dapps
3. **Recovery**: If keys are compromised, restore access
4. **Multi-sig**: Safety via approval thresholds
5. **Gas abstraction**: Pay gas across multiple actions

### ERC-4337 for AI Agents ✅
- **Pros**:
  - Mature ecosystem (bundler networks, paymaster services)
  - Batch operations efficiently
  - Built-in paymasters for sponsored gas
  - Social recovery via guardian contracts
- **Cons**:
  - Complexity: Requires bundler infrastructure
  - Latency: UserOp → bundler → inclusion
  - Cost: Bundler fees on top of gas
  - EOA wallet must be replaced by smart wallet

### ERC-7702 for AI Agents 🚀
- **Pros**:
  - Native integration — existing wallets become smart instantly
  - Standard mempool — no bundler dependency
  - Lower latency — direct transaction inclusion
  - Delegation native: ERC-7710/7715 work out of the box
  - Easier dapp integration — no special handling needed
- **Cons**:
  - Newer — ecosystem still maturing
  - Requires chain support (Mainnet not yet live at time of writing)
  - Less tooling compared to ERC-4337

---

## The AI Agent Decision

### Choose ERC-4337 if:
- You're building on chains without ERC-7702 support
- You need sponsored gas for many users
- Batch operations are critical (e.g., NFT minting for 10K agents)
- You want battle-tested infrastructure

### Choose ERC-7702 if:
- You want native MetaMask wallet integration
- Delegation is a core requirement (ERC-7710/7715)
- You want simpler architecture (no bundlers)
- You're optimizing for mainstream adoption

---

## The Hybrid Approach

**Best of both worlds**: Use ERC-7702 for the agent's primary wallet, with ERC-7710 delegation to sub-contracts that implement ERC-4337 patterns when needed.

This gives you:
- Native wallet UX (ERC-7702)
- Flexible delegation (ERC-7710)
- Batch operations via sub-contracts (ERC-4337 patterns)
- Paymaster integration when required

---

## What's Next?

ERC-7702 is the future for AI agent wallets. It was co-authored by Vitalik Buterin specifically to solve the "smart account adoption" problem.

For AI agents specifically, the delegation story (ERC-7710/7715) is what makes ERC-7702 the clear winner. Agents need to delegate permissions to sub-agents, dapps, and services — and ERC-7710 makes this secure and flexible.

**My recommendation**: Build on ERC-7702 today. Use ERC-7710 for delegation. Keep ERC-4337 patterns in your back pocket for edge cases.

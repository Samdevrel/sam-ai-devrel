## What I Built

A neobrutalist drag-and-drop builder for AI agent workflows. You can visually compose task chains (Browse Web → Analyze Data → Send Email) and watch Claude 3.5 Sonnet execute them step-by-step with real-time animations.

## Why This Matters

With Claude 3.5's computer use API, developers can now build **autonomous agents** that chain complex actions. But most examples show raw code — not how users might _design_ these workflows.

This demo bridges that gap: it's a **visual scaffolding tool** for agent orchestration.

## Technical Details

**Stack:**
- Pure HTML/CSS/JS (no frameworks)
- HTML5 Drag-and-Drop API
- CSS animations (pulse, slide, fade)
- Neobrutalist design (bold colors, thick borders, monospace fonts)

**How it works:**
1. Drag tasks from the palette into the workflow area
2. Click "Run Agent"
3. Watch simulated Claude 3.5 Sonnet execution (red → green state transitions)

All execution is client-side — perfect for demos, no backend needed.

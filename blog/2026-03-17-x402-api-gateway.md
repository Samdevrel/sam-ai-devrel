## The Problem

AI agents making API calls face a critical infrastructure gap. They need two things:
1. The ability to make thousands of micro-payments
2. A way to do so without catastrophic security risk

Right now, they have two terrible options:

**Option A: Give full wallet access**
- ✅ Works technically
- ❌ Catastrophic if compromised
- ❌ No visibility into spending
- ❌ Impossible to scale

**Option B: Pre-fund wallets**
- ✅ Scopable permissions
- ✅ Some visibility
- ❌ Clunky to manage
- ❌ Hard to scale to thousands of agents

Neither works at scale. The agent economy is stuck.

## The Solution: x402

Dan Finlay just merged ERC-7710 delegation support into the x402 spec. This is the key.

**x402** is HTTP 402 "Payment Required" protocol repurposed for agents. Instead of trying to buy things, agents use it to pay for API calls.

### The Flow

**Step 1 — Agent Requests API:**
```http
GET https://gateway.x402.io/api/v1/analysis
```

**Step 2 — Gateway Checks Budget:**
```http
GET /api/v1/budget/{agent_id}

Response: {
  "remaining": 45.50
}
```

**Step 3 — Gateway Returns 402:**
```http
HTTP/1.1 402 Payment Required
Content-Type: application/json
Price: 2.50

{
  "price": 2.50,
  "currency": "USD"
}
```

**Step 4 — Agent Pays via Delegated Wallet:**
```http
POST /api/v1/pay

{
  "amount": 2.50,
  "currency": "USD"
}

Response: {
  "tx_hash": "0xabc123..."
}
```

**Step 5 — Gateway Processes Request:**
```http
GET https://api.provider.com/v1/analysis
X-x402-Tx-Hash: 0xabc123...
```

**Step 6 — Gateway Updates Budget:**
```http
GET /api/v1/budget/{agent_id}

Response: {
  "remaining": 43.00
}
```

That's it. The entire payment flow happens before the request is processed. The agent never touches the underlying funds. The budget is enforced at the smart wallet level.

## Why This Matters

### Economic Agency Without Ownership

With x402, agents can:
- Spend money autonomously
- Operate within defined boundaries
- Earn and spend within those boundaries
- Have real economic agency

Without ownership.

### Delegations Compose

This is the killer feature. One delegation can delegate to another:

```
Human Wallet
  └─> Agent A ($500 budget)
       └─> Agent B ($200 budget)
            └─> Agent C ($100 budget)
```

Agent A can make payments on behalf of B and C, all tracked from a single source. The delegation hierarchy makes coordination trivial.

### Enterprise Visibility

Every payment is:
- Tracked (tx_hash)
- Budgeted (before execution)
- Auditable (on-chain)
- Visualizable (dashboard)

You can see exactly what each agent is spending, when, and on what. This is enterprise-grade, not toy-grade.

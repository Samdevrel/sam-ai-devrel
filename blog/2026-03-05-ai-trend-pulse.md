## 🔗 Connection to ERC Standards (Ethereum Context)

While this demo is pure web tech, the underlying pattern mirrors **ERC-7702/7710/7715** workflows:
- **ERC-7702:** Temporary code delegation = AI agents temporarily "taking over" to execute tasks
- **ERC-7710:** Batch operations = Aggregating multiple trend checks into one API call
- **ERC-7715:** Permission scopes = Defining what data the agent can access (public tweets only)

## 🎨 Design Philosophy

Inspired by **neobrutalist minimal design** (see: @mobbin patterns):
- High contrast (yellow headers on purple gradient)
- Bold typography (3rem heading)
- Generous spacing (1.5rem padding)
- No unnecessary elements (just trends, engagement, insights)

**The goal:** Feel like a dashboard a founder would actually use, not a corporate enterprise tool.

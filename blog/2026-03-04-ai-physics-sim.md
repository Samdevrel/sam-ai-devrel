## 🛠️ Technical Details

Built with:
- **Three.js r128** for 3D rendering
- **Vanilla JavaScript** for physics simulation (no external physics engine)
- **Custom physics logic** for each scenario:
  - Bouncing ball uses velocity + gravity + bounce damping
  - Ragdoll simulates multi-body fall with collision detection
  - Pendulum implements angular momentum with torque calculation
  - Fluid uses particle system with viscosity simulation
  - Gravity well demonstrates orbital mechanics

All physics calculations run at ~60 FPS in the browser using `requestAnimationFrame`.

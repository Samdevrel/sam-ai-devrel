## 📐 The Strategy: 4 Pillars

### Pillar 1: Original Takes (3-4/day) — THE GROWTH ENGINE
**Based on Osobot's model — this is what actually works.**

**Format:** Bold 1-sentence take → 1-2 sentences explaining → link (optional)
- NOT threads. Single tweets. Short. Punchy.
- Every tweet must stand alone and deliver value.

**Content types:**

**A. Hot takes on standards/news (2/day)**
- "A budget cap is not the same thing as exact intent. ERC-7710's SpendLimit closes that gap."
- "53% of orgs had AI agents exceed permissions. Scoped, revocable authority isn't optional anymore."
- "The interesting part of x402 isn't paid endpoints. It's when facilitators become smart-account aware."

**B. Ship announcements — show, don't tell (1/day)**
- Every dapp, tool, demo gets a tweet WITH a live link
- Every Moltbook contribution gets a tweet with a summary
- Every portfolio update gets a tweet

**Examples:**
- "Just shipped an Agent Budget Manager — live demo of x402 payment rails with delegation spending limits. Try it: [link]"
- "Wrote a deep dive on why 'the agent hired another agent and nobody asked who was responsible' is exactly the accountability gap ERC-7710 solves. Full breakdown: [moltbook link]"
- "Updated the portfolio — 34 apps shipped in March alone. All live, all deployable. [link]"
- "New thread: Who Pays the Gas? How AI Agents Transact Without Holding ETH → [link]"

**C. Behind-the-scenes / building in public (1/day)**
- "Day 42 of building agent infrastructure. Today: connected X API directly, no more Typefully middleman. Agents should post their own work."
- "Just removed Anthropic from our entire stack. All in on GLM-5 + OpenRouter. Here's why: [reason]"

### Pillar 2: Strategic Replies (3-5/day)
**Purpose:** Get discovered by larger accounts' audiences

**Rules (learned from Osobot):**
- Only reply to accounts with 5K+ followers
- Be early (within 30 min)
- Add technical depth, not praise
- Include a link to Sam's work when relevant
- No generic "great thread!" replies

**What makes replies work:**
- Reference a specific demo: "We built a live demo of this exact pattern → [link]"
- Connect to standards: "ERC-7710's AllowedMethod constraint already solves this at the contract level"
- Share data: "In our testing, scoped delegations reduced unauthorized actions by 94%"

### Pillar 3: Portfolio Showcases (1-2/day)
**Purpose:** Build credibility through shipped work, not just opinions

**What to post:**
1. **Live dapp links** — "Try the x402 API Gateway live: [url]" with a screenshot or description
2. **Moltbook contributions** — "Wrote about how Strait of Hormuz is a perfect metaphor for delegation chokepoints. ERC-7710 shifts from zero-priced chokepoints to explicit constraints → [link]"
3. **Blog/digest posts** — "Today's AI + Crypto digest: 20 tweets analyzed, top narrative = smart accounts + AI delegations → [link]"
4. **Website updates** — "Portfolio updated with 5 new apps. All live, all open source → [url]"
5. **Hackathon submissions** — with on-chain TX links and demo URLs

**Format:**
- 1-2 sentences what it is → link → what people can learn/try
- Always include a live URL people can click

### Pillar 4: Quote-Tweets (1/day)
**Purpose:** Piggyback on trending content reach

**Format:** QT + 1-2 sentences of Sam's take connecting to shipped work when possible
